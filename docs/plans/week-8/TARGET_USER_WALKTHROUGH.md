## 2. 统一引导与“少量指导”

开场只说明角色、任务目标和使用虚构数据，不预先演示按钮路径。参与者卡住时可提示业务目标或解释术语；记录每次提示和卡点。操作者接管、逐按钮指导或直接修改数据库帮助完成，记作“未独立完成”。这是一致执行的观察口径，不是额外课程评分规则。

预先选择每人角色对应的核心任务组，不要求普通委员会访问授权明细。协调组覆盖会议／决策／任务／活动／Dashboard；现场组覆盖报名／QR／人工更正／晚餐并验证普通角色只能见安全汇总。每人的核心组任务都完成且没有接管／逐步指导，才计入成功。
