## 实现及验收标准

### 活动检索

名称包含搜索、状态筛选、开始／结束日期组合；日期包含首尾两天，采用 Australia/Sydney 日历。默认按开始时间、ID 稳定排序，每页 20 条。筛选先在数据库执行，返回匹配总数再分页；翻页保留筛选，新提交从第一页开始。空结果、非法日期／状态、权限失败和系统失败分别显示。

日期转换复用活动核心实现。原有活动列表及近期活动调用合同保留，不更改 Dashboard 的近期定义。

### 报名检索

仅 authorised 可按姓名或邮箱进行不区分大小写的文字包含搜索。查询限定当前活动，沿用最小身份投影、用户 JWT 和现有 RLS，每页 25 条。输入最长 100 字符，搜索由显式提交触发；搜索词保留在组件内存并通过 Server Action POST 传递，不写入页面 URL 或持久化浏览器存储。数据库请求仍经既有服务端 Supabase 通道执行。

所有正则特殊字符转义为普通文字，OR 值进行 PostgREST 引号转义，不能将搜索输入解释为查询表达式。匹配在分页前完成。页面顶部报名／签到总数仍反映整个活动，不能随检索缩减。取消／恢复以及新增报名后的刷新会更新当前检索，过期异步响应不会覆盖最新结果。

只扩展读取查询，不增加身份字段，不修改写入规则、schema、RLS、migration 或生成类型。

### 可访问性

搜索区域、字段标签、日期说明、焦点样式、键盘提交、搜索结果状态播报与焦点移动明确。长文字允许换行；手机保留记录／新增视图切换。
