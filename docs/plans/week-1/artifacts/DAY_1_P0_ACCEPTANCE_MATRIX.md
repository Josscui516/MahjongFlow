## 2. 统一验收口径

| 项目 | 可测试定义 |
|---|---|
| 当前日期和时间 | 所有日期边界使用 `Australia/Sydney` 时区；自动化测试使用固定时钟 |
| 逾期 | `due_date` 早于当前本地日期且状态不是 `Completed` |
| 临期 | `due_date` 从当前本地日期起至未来 7 个日历日内（含首尾），且状态不是 `Completed` |
| 本人任务 | `assignee_id` 等于当前登录用户且状态不是 `Completed` |
| 全部待办 | 状态不是 `Completed` 的任务 |
| 简单活动进度 | 显示“已完成关联任务数／关联任务总数”；无关联任务时显示 `0/0`，不产生除零错误 |
| 即将到来的活动 | 活动开始时间不早于当前时间，按开始时间升序显示 |
| 未授权响应 | 页面和服务端返回拒绝结果；响应不得泄露参与者是否存在；数据库直接查询也必须被 RLS 拒绝 |
